# 我是如何搭好这个博客的？

我在 8 月 14 日的时候成功搭好了我的个人博客，是基于 github 中的 gmeek 搭建的。

具体步骤如下：

1. 注册 github 账号。
2. 点进[这个链接](https://github.com/new?template_name=Gmeek-template&template_owner=Meekdai)，这是一个博客模板，创建名字的时候要注意，要叫做：“你的用户名.github.io”。
3. 创建好之后，要启用pages，在仓库的Settings中Pages->Build and deployment->Source下面选择Github Actions，即可完成。
4. 现在，其实就已经建好了博客，输入仓库名就可以查看你的博客了！

现在，想要写一篇博客，可以点击仓库中的"Issues"，然后点击“new Issues”，在界面中写文章，然后一定要在Labels加一个标签，标签也可以自己创建，然后选择一个标签，最后点击Create，你就写好一篇博客了。

然后稍等片刻，打开你的博客网址（仓库名），就可以看到你新写的博客了。

如果你想要自定义博客主页的写的那些大字，就在仓库编辑 config.json，其中 “title” 是大标题，“subTitle” 是下面的小字，“avatarUrl”后面要放你的图标链接，这样就完成了自定义。

这就是搭博客的教程，快去试一试吧！
